# PDF Document Generation Skill (PDFKit & jsPDF Documentation)

The PDF Document Generation Skill enables agents and sub-agents to programmatically generate formatted PDF documents, reports, invoices, and certificates using **PDFKit** and **jsPDF**.

---

## 1. Overview & Setup

### Installation
```bash
npm install pdfkit @types/pdfkit
# or for browser/client-side PDF generation:
npm install jspdf
```

---

## 2. PDFKit API Usage (Node.js Server-Side PDF Generation)

### Initialization & Document Stream Setup
```typescript
import PDFDocument from "pdfkit";
import fs from "node:fs";

const doc = new PDFDocument({
  size: "A4", // A4: 595.28 x 841.89 points
  margins: { top: 50, bottom: 50, left: 50, right: 50 },
  info: {
    Title: "YAAA Technical Audit Report",
    Author: "YAAA AI System",
    Subject: "Architecture & Verification Log"
  }
});

// Pipe output stream to file
doc.pipe(fs.createWriteStream("report.pdf"));
```

## 4. Multi-Column Tables & Layout Boxes

### Drawing Tables with Lines and Cell Borders
```typescript
function drawTable(doc: PDFDocument, startY: number, headers: string[], rows: string[][]) {
  const startX = 50;
  const colWidths = [120, 250, 125];
  let currentY = startY;

  // Header Row Background
  doc.rect(startX, currentY, 495, 25).fill("#313244");

  // Header Text
  let currentX = startX;
  doc.fillColor("#FFFFFF").font("Helvetica-Bold").fontSize(11);
  headers.forEach((header, colIdx) => {
    doc.text(header, currentX + 8, currentY + 7, { width: colWidths[colIdx] - 16, align: "left" });
    currentX += colWidths[colIdx];
  });

  currentY += 25;

  // Data Rows
  doc.font("Helvetica").fontSize(10);
  rows.forEach((row, rowIdx) => {
    const rowHeight = 22;
    const bg = rowIdx % 2 === 0 ? "#1E1E2E" : "#181825";
    doc.rect(startX, currentY, 495, rowHeight).fill(bg);

    let cellX = startX;
    doc.fillColor("#CDD6F4");
    row.forEach((cellText, colIdx) => {
      doc.text(cellText, cellX + 8, currentY + 6, { width: colWidths[colIdx] - 16, align: "left" });
      cellX += colWidths[colIdx];
    });

    currentY += rowHeight;
  });

  return currentY;
}
```

## 6. Page Numbers & Finalizing Stream

```typescript
// Page Number Footer Callback
const range = doc.bufferedPageRange();
for (let i = range.start; i < range.start + range.count; i++) {
  doc.switchToPage(i);
  doc
    .fillColor("#6C7086")
    .fontSize(9)
    .text(`Page ${i + 1} of ${range.count}`, 50, 800, { align: "center", width: 495 });
}

// Finalize PDF File Creation
doc.end();
```

## 7. jsPDF Usage (Client-Side / In-Browser PDF Generation)

```typescript
import { jsPDF } from "jspdf";

const pdf = new jsPDF("p", "pt", "a4");

// Add Title
pdf.setFont("helvetica", "bold");
pdf.setFontSize(22);
pdf.setTextColor(30, 30, 46);
pdf.text("System Audit Summary", 40, 50);

// Add Paragraph
pdf.setFont("helvetica", "normal");
pdf.setFontSize(12);
pdf.setTextColor(80, 80, 100);
pdf.text("Automated PDF report generated by YAAA System.", 40, 80);

// Save to disk
pdf.save("summary.pdf");
```

---

## 8. Best Practices for Agents

1. **Explicit Dimensions**: Standard A4 page is $595.28 \times 841.89$ points.
2. **Page Flow**: Always track `currentY` and call `doc.addPage()` when `currentY > 750`.
3. **Stream Safety**: Ensure `doc.end()` is invoked after piping to disk stream.
